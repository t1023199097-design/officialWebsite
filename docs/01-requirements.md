# 需求文档

## 项目目标

- 将 BeeFintech 官网从静态宣传页升级为动态服务平台。
- 满足比赛基础要求：品牌宣传、预约演示 API 对接。
- 为至少 1 项增值服务功能提前完成架构预留和扩展入口。

## 首版范围

- 官网公开门户
- 预约演示表单与后端 API
- 最小可用后台
- 三类增值服务统一预留

## 用户角色

- 潜在客户：浏览官网、提交预约
- 业务/运营同学：查看预约、后续维护内容与服务模块
- 开发同学：扩展 API、接入增值服务、维护文档

## 非目标

- 本期不做完整 RBAC
- 本期不承诺三类增值模块全部实现具体业务逻辑
- 本期不做完整生产级发布流水线
