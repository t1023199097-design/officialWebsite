# 架构说明

## 总体结构

- `apps/web`：官网门户与最小后台
- `apps/api`：统一 API、预约编排、后台认证、模块注册
- `docs`：比赛交付文档
- `infra`：本地数据库初始化和环境支撑

## 前端职责

- 品牌官网展示
- 预约表单交互
- 后台页面壳
- 管理端 API 调用

## 后端职责

- 公开 API
- 后台 API
- 单管理员会话认证
- 预约数据入库
- 预留增值服务模块注册

## 模块边界

- `demo`：预约演示
- `admin.auth`：后台登录和会话
- `modules`：增值服务注册表
- `platform`：平台概览和公开聚合信息
- `content` / `support` / `tools`：增值服务实体预案

## 扩展方向

- 对接真实预约系统
- 引入内容管理能力
- 增加 FAQ / 工单服务
- 实现 ROI 计算器与术语字典
- 升级后台权限模型
