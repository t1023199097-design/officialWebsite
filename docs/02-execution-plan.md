# 规划执行文档

## 已确定技术路线

- 单仓 `monorepo`
- 前端：`Next.js`
- 后端：`Spring Boot`
- 架构：前端门户 + 后端聚合平台
- 数据：`MySQL + 本地对象目录`

## 分阶段执行

1. 搭建单仓目录和根配置
2. 搭建 Spring Boot API 骨架与测试
3. 搭建 Next.js 门户和后台骨架
4. 接通预约演示 API
5. 预留三类增值服务模块的路由、接口、后台入口
6. 补齐比赛文档、启动说明与验证记录

## 交付边界

- 必做：官网、预约 API、最小后台
- 预留：资讯专栏、FAQ/工单、ROI/术语工具
- 后续可扩：真实第三方预约接口、内容发布流、权限系统
