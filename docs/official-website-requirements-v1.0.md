## 一、項目背景

Beefintech -- Lifebee 主要服務於保險經紀行業，通過數字化服務系統協助保險經紀公司提升客戶管理、保單跟進、業務流程、團隊協作與資料整理效率。

現階段官網需要從單一品牌展示，升級為兼具品牌宣傳、業務介紹、線索收集、內容服務、客戶支持與工具服務的綜合型官方網站。網站既要讓首次訪問者快速理解 Lifebee 的公司定位與產品價值，也要為潛在客戶提供預約演示入口，並為後續內容運營與客戶服務打好基礎。

第一階段重點是建立清晰、可信、具有科技感的官網框架，讓官網具備對外展示、客戶轉化與基礎服務承接能力。

## 二、項目目標

1. 建立 Beefintech -- Lifebee 專業、可信、科技感強的品牌形象。
2. 清晰展示 Lifebee 面向保險經紀服務系統的核心價值與應用場景。
3. 建立「預約演示」入口，方便潛在客戶提交聯絡信息與需求。
4. 建立三類服務能力入口：內容服務、客戶賦能、工具服務。
5. 支持電腦端與手機端瀏覽，確保不同設備上的閱讀與操作體驗一致順暢。
6. 為後續內容更新、客戶支持、工具服務擴展預留清晰位置。

## 三、官網定位

### 3.1 品牌定位

Beefintech -- Lifebee 是面向保險經紀公司的保險科技服務系統，幫助企業提升業務管理效率、客戶服務能力、團隊協作質量與運營可視化水平。

### 3.2 官網定位

官網定位為「品牌展示 + 業務說明 + 客戶轉化 + 服務入口」的綜合型官方網站。

網站需要承擔以下作用：

1. 對外展示公司品牌、產品能力與行業理解。
2. 幫助潛在客戶快速判斷 Lifebee 是否適合自身業務需求。
3. 引導訪客預約演示、提交合作意向。
4. 為現有客戶提供常見問題、在線工單、更新日誌等服務入口。
5. 通過資訊、政策解讀、工具等內容，提升官網的專業度與長期訪問價值。

### 3.3 目標訪問者

1. 保險經紀公司管理層：關注效率提升、團隊管理、客戶服務與長期成本。
2. 保險經紀業務負責人：關注業務流程、保單跟進、客戶資料整理與協作效率。
3. 合作夥伴：關注公司能力、服務範圍與合作可能性。
4. 行業關注者：關注保險科技資訊、政策解讀與行業趨勢。
5. 現有客戶：查找常見問題、提交服務需求、了解產品更新。

## 四、設計風格要求

### 4.1 整體風格

官網整體應呈現科技感、金融感、專業感與可信感。視覺上可以使用具有未來感的光效、數字化圖形、產品工作台示意、數據展示等元素，但應避免過度花哨，確保網站看起來穩重、清晰、易讀。

### 4.2 視覺關鍵詞

1. 科技金融
2. 專業可信
3. 清晰高效
4. 數字化服務
5. 保險行業專屬
6. 企業級服務
7. 視覺衝擊力

### 4.3 首屏視覺方向

首頁第一屏需要有強烈的品牌識別與視覺記憶點。建議使用科技感背景、產品能力示意、數據流動感或抽象數字化視覺，突出「保險經紀服務系統」與「科技賦能」的定位。

首屏需要清楚展示：

1. 品牌名稱：Beefintech -- Lifebee
2. 核心主張：面向保險經紀公司的數字化服務系統
3. 價值說明：提升效率、優化服務、強化管理、支持增長
4. 主要行動入口：預約演示

## 五、配色建議

### 5.1 主色建議

1. 深藍色：用於品牌主視覺、重要標題與專業氛圍營造。
2. 科技藍：用於按鈕、重點信息、圖形高光與互動提示。
3. 青綠色：用於輔助點綴，表達效率、智能、增長與活力。
4. 白色與淺灰色：用於正文背景與信息區塊，提升可讀性。
5. 深灰色：用於正文文字，確保長內容閱讀舒適。

### 5.2 配色原則

1. 整體以深藍、科技藍、白色為主，形成科技金融風格。
2. 青綠色只作為點綴，不宜大面積使用。
3. 重要按鈕顏色需醒目，與普通文字和背景形成明顯區分。
4. 手機端需保持文字清晰，避免背景過暗導致閱讀困難。
5. 不建議使用過多鮮艷顏色，以免削弱金融服務的專業感。

## 八、基礎功能需求

### 8.1 品牌宣傳功能

1. 官網需清楚展示 Beefintech -- Lifebee 的品牌名稱、行業定位與核心價值。
2. 首頁需突出保險經紀服務系統定位。
3. 網站需通過文字、視覺、場景說明和服務能力展示，建立專業可信形象。
4. 網站需有明確的預約演示入口，方便訪客進一步了解。

### 8.2 預約演示信息對接

1. 訪客可通過預約演示頁提交需求。
2. 提交內容需包含基礎聯絡信息與業務需求。
3. 提交後需給出清晰的成功提示。
4. 公司內部人員需能獲取訪客提交的信息，用於後續聯絡。
5. 後續可擴展為自動通知、客戶跟進記錄、銷售進度管理等能力。

### 8.3 內容服務類功能

包括保險科技資訊、行業政策解讀專欄等。

需求如下：

1. 支持展示內容分類。
2. 支持文章列表展示。
3. 支持文章詳情閱讀。
4. 支持按時間展示最新內容。
5. 每篇內容需包含標題、摘要、日期、分類與正文。
6. 內容語氣需專業、客觀、易懂，避免空泛宣傳。

### 8.4 客戶賦能類功能

包括常見問題自助查詢、在線工單、更新日誌發布等。

需求如下：

1. 常見問題需按類型整理，方便訪客快速找到答案。
2. 在線工單需支持訪客提交問題與需求。
3. 工單提交後需有明確反饋，避免訪客不確定是否提交成功。
4. 更新日誌需按時間倒序展示。
5. 更新日誌需讓客戶了解產品與服務持續優化情況。

### 8.5 工具服務類功能
