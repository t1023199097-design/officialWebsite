## 2. 項目背景

LifeBee 是面向保險經紀公司的數字化經營管理系統，核心價值是協助保險經紀公司提升展業效率、流程管理能力、團隊協同能力和數據化經營水平。

本次官網改造旨在將 Beefintech -- Lifebee 官網從基礎展示型網站升級為品牌推廣與商務轉化入口。網站需面向潛在客戶清楚呈現公司定位、服務價值、行業成果和預約諮詢路徑，幫助訪客快速理解 LifeBee 能為保險經紀行業創造的價值。

## 3. 項目目標

| 目標類型 | 具體目標 |
| --- | --- |
| 品牌目標 | 建立專業、可信、科技金融感的品牌形象 |
| 業務目標 | 吸引保險中介機構、經紀公司、獨立 IFA 和合作伙伴了解 LifeBee |
| 轉化目標 | 引導潛在客戶提交預約諮詢或演示需求 |
| 內容目標 | 通過保險科技資訊與行業政策解讀建立專業度 |
| 體驗目標 | 保證電腦端與手機端均可清晰瀏覽、快速理解、順暢提交需求 |

## 4. 官網定位

### 4.1 品牌定位

Beefintech -- Lifebee 是面向保險經紀公司的全流程數字化經營管理系統，服務於保險經紀業務中的展業、管理、協同和數據化經營需求。

### 4.2 官網定位

官網定位為 LifeBee 對外品牌展示與商務轉化入口，主要承擔以下任務：

1. 展示 Beefintech -- Lifebee 的公司背景與品牌定位。
2. 說明 LifeBee 能為保險經紀公司創造的核心價值。
3. 展示市場業務規模、服務成果和行業覆蓋情況。
4. 提供預約諮詢演示入口，承接潛在客戶轉化。
5. 通過內容服務建立專業形象與行業信任。

## 5. 目標用戶

### 8.1 整體風格

1. 風格方向：科技金融、專業可信、簡潔清晰。

### 8.2 配色建議

## 10. 頁面需求

### 10.1 首頁

首頁需作為官網核心入口，清楚呈現品牌定位、服務價值、市場成果和預約轉化入口。

| 模塊 | 內容要求 |
| --- | --- |
| 頂部導覽 | 首頁、品牌功能介紹、市場業務規模、預約諮詢演示、關於我們 |
| 首屏品牌區 | 品牌名稱、主標題、副標題、預約諮詢演示入口、品牌科技視覺 |
| 品牌功能介紹 | 展示 3 至 4 個核心服務能力大模塊，每個模塊只呈現名稱、服務對象和價值說明 |
| 市場業務規模 | 展示服務伙伴、活躍用戶、業務覆蓋地區、服務成果等可信信息 |
| 預約諮詢演示 | 引導訪客提交諮詢或演示需求，文案需簡潔清晰 |
| 關於我們 | 簡要展示公司背景、行業經驗、產品理念和了解更多入口 |

### 10.2 品牌功能介紹頁

本頁需以大模塊方式介紹 LifeBee 的核心服務能力，重點說明服務如何幫助客戶實現價值。

| 模塊 | 服務對象 | 價值說明 |
| --- | --- | --- |
| 展業效率提升 | 前線顧問、銷售團隊、獨立 IFA | 協助提升資料獲取、方案準備、客戶跟進和業務提醒效率 |
| 經營管理提效 | 管理層、行政運營、財務團隊 | 協助公司從分散管理走向集中化、可視化管理 |
| 流程協同與數據賦能 | 需要標準化流程與數據化管理的保險經紀公司 | 協助企業看清流程、看見進度、看懂經營結果 |
| 長期服務支持 | 現有客戶與潛在客戶 | 傳達 LifeBee 作為長期數字化服務伙伴的支持能力 |

### 10.3 市場業務規模頁

本頁需展示 LifeBee 在行業內的服務成果與市場覆蓋情況。

| 模塊 | 內容要求 |
| --- | --- |
| 服務伙伴 | 展示已服務保險中介機構、經紀公司、獨立 IFA 或合作伙伴情況 |
| 市場覆蓋 | 展示香港市場服務基礎，以及澳門、台灣、新加坡等亞太核心市場覆蓋情況 |
| 服務成果 | 展示效率提升、流程改善、服務能力提升、數據管理提升等成果方向 |
| 數據要求 | 具體數字需由公司內部確認；市場份額需標註數據來源和統計口徑 |

### 10.4 預約諮詢演示頁

本頁需承接潛在客戶轉化，表單內容保持簡潔。

| 表單內容 | 說明 |
| --- | --- |
| 姓名 | 用於後續聯絡 |
| 公司名稱 | 用於識別客戶所在機構 |
| 聯絡方式 | 用於商務團隊跟進 |
| 公司所在地 | 用於了解服務區域 |
| 團隊規模 | 用於初步判斷服務需求 |
| 希望了解的服務方向 | 可選展業效率提升、經營管理提效、流程協同與數據賦能、市場合作與商務諮詢 |
| 補充需求 | 供訪客填寫其他說明 |

提交後需顯示成功提示，並告知將由團隊跟進聯絡。

### 10.5 關於我們頁

本頁需展示公司可信度和行業專業度。

| 模塊 | 內容要求 |
| --- | --- |
| 公司介紹 | 介紹 BeeFintech / LifeBee 的公司背景 |
| 行業理解 | 展示對香港保險經紀行業的理解與服務經驗 |
| 產品理念 | 展示合規驅動、效率為王、數據賦能等理念 |
| 服務優勢 | 展示公司在產品、服務、行業經驗方面的優勢 |
| 長期願景 | 展示公司服務保險經紀行業數字化升級的長期方向 |
| 預約入口 | 提供預約諮詢演示入口 |

### 10.6 內容服務頁

本頁為本期保留的增值服務類功能，需以內容服務為主，支撐品牌專業形象和潛在客戶信任建立。

| 內容類型 | 內容要求 |
| --- | --- |
| 保險科技資訊 | 展示保險科技相關行業資訊、發展趨勢和市場觀察 |
| 行業政策解讀專欄 | 展示保險經紀相關政策、行業規範和市場變化解讀 |

內容呈現要求：

1. 支持標題、摘要、日期和分類展示。
2. 支持文章列表與文章詳情閱讀。
3. 內容需簡潔、可信，服務於品牌專業度、行業信任和潛在客戶認知建立。

### 10.7 聯絡我們頁

本頁需包含：

1. 公司名稱。
2. 商務合作入口。
3. 渠道合作入口。
4. 客戶服務聯絡入口。
5. 電郵或電話。
6. 預約諮詢演示入口。

### 10.8 404 頁

本頁需包含：

1. 頁面不存在提示。
2. 返回首頁入口。
3. 預約諮詢演示入口。
4. 聯絡我們入口。

## 12. 電腦端與手機端適配要求

### 12.1 電腦端

1. 首屏需突出品牌定位、服務價值和預約入口。
2. 首頁四個核心維度需清楚分段。
3. 品牌功能介紹頁需便於快速掃描。
4. 市場業務規模與成果展示需清晰、可信。
5. 預約諮詢演示入口需清晰可見。

### 12.2 手機端

1. 首屏優先展示品牌主張和預約諮詢演示入口。
2. 導覽可簡化展示。
3. 內容需上下分段展示。
4. 表單需適合手機填寫。
5. 文字、按鈕、圖片不可遮擋或擠壓。

## 13. 內容與排版要求

1. 官網需先展示品牌定位，再展示服務價值和市場成果，最後引導預約諮詢演示。
2. 首頁需聚焦品牌、價值、成果和預約轉化。
3. 服務介紹需突出「能幫客戶創造什麼價值」。
4. 文案需專業、清晰、可信。
5. 避免誇大承諾。
6. 市場份額、服務伙伴數量、活躍用戶等數據需標註來源或由公司內部確認。
7. 所有頁面品牌名稱保持一致。
