## 1. 項目背景

LifeBee 是面向保險經紀公司的數字化經營管理系統，覆蓋銷售展業、產品資料、客戶跟進、預約簽單、新單核保、保單服務、續保提醒、佣金管理、渠道管理與公司經營數據。

本次官網 V2.0 需在 V1.0 基礎上，補充 LifeBee APP 與 Admin 後台的真實產品能力，讓官網從基礎品牌展示升級為「品牌展示 + 產品能力說明 + 業務場景呈現 + 預約轉化」的正式官網。

## 2. 官網定位

### 2.1 品牌定位

Beefintech -- Lifebee 是保險經紀公司全流程數字化經營管理系統，協助企業統一管理產品資料、客戶、預約、新單、保單、續保、佣金、渠道和經營數據。

### 2.2 官網定位

官網定位為 LifeBee 對外品牌與產品能力展示平台，主要承擔以下任務：

1. 建立專業、可信、科技金融的品牌形象。
2. 清晰展示 APP 端與 Admin 端能力。
3. 展示 LifeBee 對保險經紀公司核心業務流程的支持。
4. 引導潛在客戶提交預約演示。
5. 提供內容服務、客戶支持和工具服務入口。

## 3. 目標用戶

1. 保險經紀公司管理層：關注公司業績、團隊管理、流程效率和經營數據。
2. 業務代表與銷售團隊：關注產品資料、計劃書、客戶跟進、保單提醒和介紹費。
3. 行政與運營團隊：關注預約、新單、保單、文件、資訊和服務咨詢管理。
4. 財務與佣金負責人：關注佣金合約、佣金估算、發放、渠道賬單和財務報表。
5. 合作渠道與合作夥伴：關注系統能力、合作流程和長期服務能力。
6. 現有客戶：關注常見問題、操作指引、服務咨詢與產品更新。

## 4. 核心價值主張

官網需圍繞以下價值展開：

1. 產品資料集中管理：市場優惠、保險公司資料、產品小冊子、官方文件、知識庫。
2. 銷售展業效率提升：產品對比、保費試算、計劃書、計劃書對比、財務需求分析。
3. 業務流程狀態可見：預約、新單、保單、續保、待辦、日程提醒。
4. 前後台協同：APP 端與 Admin 後台信息同步，減少重複溝通。
5. 佣金與賬單透明：智能合約、介紹費帳單、佣金估算、佣金發放、渠道賬單。
6. 公司級管理能力：數據看板、客戶管理、渠道管理、銷售分組、財務報表。

## 5. 視覺與設計要求

### 5.1 整體風格

1. 風格方向：科技金融、專業可信、清晰高效。
2. 視覺重點：雙端工作台、業務流程、數據看板、產品資料、保單狀態、佣金賬單。
3. 表達方式：少用空泛口號，多用具體業務場景和功能展示。
4. 頁面體驗：信息層級清楚，便於快速瀏覽和理解。

### 5.2 配色建議

1. 主色：深藍、科技藍。
2. 輔助色：青綠、淺灰、白色。
3. 文字色：深灰或黑灰。
4. 財務、佣金類內容需保持專業克制，不使用過度刺激色彩。

### 5.3 首屏要求

首頁首屏需包含：

1. 品牌名稱：Beefintech -- Lifebee。
2. 主標題：保險經紀公司全流程數字化經營管理系統。
3. 副標題：連接銷售 APP、Admin 後台、產品資料、業務流程與佣金管理。
4. 主要按鈕：預約演示。
5. 次要按鈕：查看產品能力。
6. 視覺元素：APP + Admin 雙端工作台展示。
